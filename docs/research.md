# 淘宝 AI 试衣调研与衣序决策

调研日期：2026-10-24。依据公开报道与服务作者资料，未登录淘宝逐屏实测，不声称复制其当前全部入口或精确尺码能力。

## 产品流程

[2025-06-24 公开报道](https://finance.sina.com.cn/cj/2025-06-24/doc-infcerum5446138.shtml)描述通过照片和身材档案选择服装、查看上身效果。用户关心「放到我身上怎么样」，不仅是商品静态图片。报道中的入口属于当时情况，不代表当前全部账号。

衣序将这一流程扩展到用户已有衣服：入库、找回单品、尝试组合、生成效果、保存并再次穿着。无需购买商品或登录。品牌、界面和素材原创。

| 用户诉求 | 产品落点 |
| --- | --- |
| 衣服不少，出门仍不知道穿什么 | 用实际衣橱按场景组合，保存成套搭配 |
| 不确定上身视觉效果 | 个人全身照 + 服装图 → 真实换装模型 |
| 照片很多，难找某件衣服 | 分类、名称/颜色/品牌搜索、收藏、季节筛选 |
| 喜欢的搭配下次记不起来 | 自动保存试衣历史、穿搭集和穿着足迹 |
| 照片与档案属于私人信息 | 默认本地存储，外发确认，可导出完整备份 |

## 模型与实测

默认使用作者 [FASHN VTON 1.5](https://github.com/fashn-AI/fashn-vton-1.5) 公开演示。它支持人像与服装图，以及上装、下装和连体服装类别。[模型卡](https://huggingface.co/fashn-ai/fashn-vton-1.5)标明 Apache-2.0。应用不打包模型权重。

已实际请求：原创 AI 人像配作者公共服装样本生成输出；随后从浏览器界面上传本项目白衬衫，完成生成、图片本地化、保存和刷新恢复。记录与截图位于 `artifacts/`。这证明本次调用可用，不是长期服务可用率承诺。

[IDM-VTON 作者演示](https://huggingface.co/spaces/yisol/IDM-VTON)支持上装，本次进入队列后返回服务端错误。作为研究备用并如实显示错误，模型具有非商业许可限制。

[阿里云 AI试衣 Plus 参考](https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/aitryon-plus-api)用于理解商业服务异步任务结构。可选适配只有协议测试；账户、地域、图片支持和计费需自行验证。默认体验使用实测跑通的 FASHN。

客户端依照 [Gradio 官方流程](https://www.gradio.app/guides/querying-gradio-apps-with-curl)呈现队列与结果，不自动重复提交。最长等待 4 分钟；本地取消后，已开始的服务端任务仍可能继续。生成图片下载到本地，不依赖临时远程链接。

## 技术

原生 Android Java 宿主 + 本地 React，IndexedDB 存储压缩图片与数据，系统接管相册、相机和文件保存。参考 [Android 本地资源建议](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)，使用 HTTPS 本地资源域并禁用文件跨域访问，页面随 APK 安装。

身高体重只记录，不把二维换装当作物理尺寸试衣。场景搭配明确为本地规则，不编造实时天气或 AI 评分。

## 原创素材

`public/images/editorial.png` 由内置 imagegen 生成。提示：成年东亚女性，深灰宽松西装、白 T 恤、米色高腰阔腿裤、黑乐福鞋；暖色极简公寓、秋日窗边自然光、完整站姿、真实布料、编辑风摄影；无文字、水印、标识或界面。仅作灵感封面与明确标注的示例模特。

`scripts/create-sample-art.mjs` 绘制 8 件原创 SVG 衣物，作为可删除的初始示例，不宣称用户实拍商品。
